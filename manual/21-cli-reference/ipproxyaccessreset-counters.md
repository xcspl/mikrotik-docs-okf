## ip/proxy/access/reset-counters 
**Type:** Command

Resets the `hits` counter of the given rules in [`/ip/proxy/access`](https://manual.mikrotik.com/docs/cli-reference/ip/proxy/access/), for example `/ip/proxy/access/reset-counters [find comment=test]`. For an overview, see [Web Proxy](https://manual.mikrotik.com/docs/network-management/proxy/web-proxy).
