## tool/sniffer/stop 
**Type:** Command

Stops the sniffer. The captured packets stay in memory for 10 minutes, or until the next [`start`](https://manual.mikrotik.com/docs/cli-reference/tool/sniffer/start): list them in [`packet`](https://manual.mikrotik.com/docs/cli-reference/tool/sniffer/packet), [`protocol`](https://manual.mikrotik.com/docs/cli-reference/tool/sniffer/protocol), [`host`](https://manual.mikrotik.com/docs/cli-reference/tool/sniffer/host) and [`connection`](https://manual.mikrotik.com/docs/cli-reference/tool/sniffer/connection), or write them to a file with [`save`](https://manual.mikrotik.com/docs/cli-reference/tool/sniffer/save).
