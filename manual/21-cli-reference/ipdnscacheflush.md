## ip/dns/cache/flush 
**Type:** Command

Empties the DNS cache. Static entries from [`/ip/dns/static`](https://manual.mikrotik.com/docs/cli-reference/ip/dns/static) stay available. For an overview, see [DNS](https://manual.mikrotik.com/docs/network-management/dns).
